# quickscript
A programming language lexer, parser and interpreter written in C++ as an exercise in language 
and compiler design.

## Initial Goals
- [x] Lexer
- [x] Parser
- [x] Type checker
- [x] Semantic analyzer
- [ ] Compiler
- [ ] Interpreter

Basically, get the language to parse, check the types, compile it to an IR and then be able to 
interpret that IR.

## Future goals

### Struct Methods
Functions which belong to structs, these shouldn't be too hard to slot into the language. They can
be implemented in a similar way as C++, where before the AST even reaches the compiler, the struct 
methods are transformed into free floating functions with the struct type prepended to the method 
name.

### Constructors
Constructors are already automatically generated by the Semantic Transformer that happens right 
before compilation. having users declare the constructors themselves wouldn't be that hard I 
imagine.

### Reflection
Again, since all type information is preserved, including some native type like `Type` that can be
accessed with a `typeof` operator shouldn't be difficult.
