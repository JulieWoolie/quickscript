# quickscript
A programming language lexer, parser and interpreter written in C++ as an exercise in language 
and compiler design.

#### File suffixes:
- `.qscr` - quickscript source files
- `.qscr-ir` - Text representation of quickscript IR files
- `.qsir` - Binary quickscript IR file

## Building
Several parts of the code base are made up of generated code files, mostly generated by 
deno scripts. Currently, they are executed with powershell scripts. To run the generator scripts do:
```powershell
.\run-gen-scripts.ps1
```
